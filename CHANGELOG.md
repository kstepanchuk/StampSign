# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-11-06

### Добавлено
- Перетаскивание PDF и `.sig` в окно, автоматический поиск парного `X.pdf.sig`.
- Штамп «ДОКУМЕНТ ПОДПИСАН ЭЛЕКТРОННОЙ ПОДПИСЬЮ» с данными из подписи (серийный номер, владелец, срок действия, время подписания).
- Свободное размещение штампа: перетаскивание, изменение размера, прилипание, стрелки, пресеты, числовые поля, выбор страницы или все страницы.
- Выбор часового пояса для отображаемых дат (по умолчанию московское).
- Проверка подписи на Swift: Стрибог-256/512, ЭЦП ГОСТ Р 34.10-2012, срок действия сертификата, подпись УЦ.
- Вложение исходного PDF и `.sig` в итоговый файл, проверка штампованного PDF по вложениям.
- Иконка приложения, сборка `build.sh`, служебный режим командной строки, тесты и CI.
